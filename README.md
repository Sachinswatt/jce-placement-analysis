# College Placement Data Analysis

##  Project Overview

This project analyzes college placement data to understand placement trends, recruiting companies, and salary package patterns across different batches.

The objective is to help the college placement cell make data-driven decisions and improve future placement strategies and training programs.

##  Problem Statement

The college placement cell wants to analyze placement data to:

- Track placement trends across batches and companies
- Identify patterns in student selections
- Compare salary/package trends
- Identify companies with high recruitment
- Identify companies offering higher salary packages
- Support future placement strategies and training programs
